## Usage

```sh
pip install niryukti
niryukti devices
niryukti solve model.mps --device cpu
npm install niryukti
# If npm blocks dependency install scripts, review and run the native build:
node node_modules/niryukti/install.js
```

npm needs Node >=18, CMake >=3.24 and a C++20 compiler. Its API accepts a model
path or native JSON object, with time limit/tolerance and AbortSignal options.
Python import compatibility through `vantage` remains; new applications should
use `niryukti`. Existing developer build scripts retain a `vantage` executable
copy; public CLI installation uses `niryukti`.
